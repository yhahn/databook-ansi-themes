# Theme: Northstar

- Dark: yes
- Background: `#0b0f1a`
- Foreground: `#f5f7fb`
- Cursor: `#fcd34d`
- Cursor text: `#0b0f1a`
- Selection: `#1f2937`
- Selection text: `#ffffff`
- Contrast: 17.84
- Same brights: 0
- Licence: unstated

- Default: no

- Made from: [iTerm2-Color-Schemes, ghostty/Northstar](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Northstar)

The dark terminal theme Northstar: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
