# Theme: Neopolitan

- Dark: yes
- Background: `#271f19`
- Foreground: `#ffffff`
- Cursor: `#ffffff`
- Cursor text: `#bfbfbf`
- Selection: `#253b76`
- Selection text: `#ffffff`
- Contrast: 16.20
- Same brights: 7
- Licence: unstated
- Licence from:
- Default: no
- Credit: The theme Neopolitan was created by [daytonn](https://github.com/daytonn/iTerm2-Color-Schemes)
- Made from: [iTerm2-Color-Schemes, ghostty/Neopolitan](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Neopolitan)

The dark terminal theme Neopolitan: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
