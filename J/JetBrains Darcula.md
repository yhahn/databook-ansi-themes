# Theme: JetBrains Darcula

- Dark: yes
- Background: `#202020`
- Foreground: `#adadad`
- Cursor: `#ffffff`
- Cursor text: `#000000`
- Selection: `#1a3272`
- Selection text: `#adadad`
- Contrast: 7.26
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no

- Made from: [iTerm2-Color-Schemes, ghostty/JetBrains Darcula](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/JetBrains%20Darcula)

The dark terminal theme JetBrains Darcula: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
