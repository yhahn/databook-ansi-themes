# Theme: Zenburn

- Dark: yes
- Background: `#3f3f3f`
- Foreground: `#dcdccc`
- Cursor: `#73635a`
- Cursor text: `#000000`
- Selection: `#21322f`
- Selection text: `#c2d87a`
- Contrast: 7.60
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The scheme Zenburn was inspired by the [Zenburn](http://sunaku.github.io/zenburn-terminal-color-scheme.html) version created by Suraj N. Kurapati.
- Made from: [iTerm2-Color-Schemes, ghostty/Zenburn](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Zenburn)

The dark terminal theme Zenburn: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
