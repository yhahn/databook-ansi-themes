# Theme: Primary

- Dark: no
- Background: `#ffffff`
- Foreground: `#000000`
- Cursor: `#000000`
- Cursor text: `#ffffff`
- Selection: `#656565`
- Selection text: `#eeeeee`
- Contrast: 21.00
- Same brights: 5
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Primary theme was created by [jayanthkoushik](https://github.com/jayanthkoushik) based on [Google's vim colorscheme](https://github.com/google/vim-colorscheme-primary).
- Made from: [iTerm2-Color-Schemes, ghostty/Primary](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Primary)

The light terminal theme Primary: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
