# Theme: 5150 Mode

- Dark: yes
- Background: `#082820`
- Foreground: `#ecf4db`
- Cursor: `#d5e875`
- Cursor text: `#082820`
- Selection: `#245444`
- Selection text: `#ffffff`
- Contrast: 13.88
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no

- Made from: [iTerm2-Color-Schemes, ghostty/5150 Mode](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/5150%20Mode)

The dark terminal theme 5150 Mode: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
