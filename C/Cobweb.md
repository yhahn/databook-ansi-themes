# Theme: Cobweb

- Dark: yes
- Background: `#20272d`
- Foreground: `#eef1f3`
- Cursor: `#e7ebee`
- Cursor text: `#20272d`
- Selection: `#3d454c`
- Selection text: `#ffffff`
- Contrast: 13.32
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no

- Made from: [iTerm2-Color-Schemes, ghostty/Cobweb](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Cobweb)

The dark terminal theme Cobweb: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
