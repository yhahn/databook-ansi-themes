# Theme: Charcoal

- Dark: yes
- Background: `#0d0d0d`
- Foreground: `#c4c4c4`
- Cursor: `#d0d0d0`
- Cursor text: `#0d0d0d`
- Selection: `#2e2e2e`
- Selection text: `#e0e0e0`
- Contrast: 11.14
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Charcoal theme was created by [Vyom Jain](https://github.com/VyomJain6904). A deep-black grayscale theme (also available for bat and OpenCode at [charcoal-theme](https://github.com/VyomJain6904/charcoal-theme)).
- Made from: [iTerm2-Color-Schemes, ghostty/Charcoal](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Charcoal)

The dark terminal theme Charcoal: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
