# Theme: Dark Modern

- Dark: yes
- Background: `#1f1f1f`
- Foreground: `#cccccc`
- Cursor: `#ffffff`
- Cursor text: `#000000`
- Selection: `#3a3d41`
- Selection text: `#e0e0e0`
- Contrast: 10.26
- Same brights: 1
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Dark Modern theme was created by [zasdaym](https://github.com/zasdaym). It is based on the default VS Code theme.
- Made from: [iTerm2-Color-Schemes, ghostty/Dark Modern](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Dark%20Modern)

The dark terminal theme Dark Modern: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
