# Theme: Doom One

- Dark: yes
- Background: `#282c34`
- Foreground: `#bbc2cf`
- Cursor: `#51afef`
- Cursor text: `#1b1b1b`
- Selection: `#42444b`
- Selection text: `#bbc2cf`
- Contrast: 7.82
- Same brights: 4
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Doom One theme was based on [Emacs Doom default theme](https://github.com/hlissner/emacs-doom-themes)
- Made from: [iTerm2-Color-Schemes, ghostty/Doom One](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Doom%20One)

The dark terminal theme Doom One: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
