# Theme: Rippedcasts

- Dark: yes
- Background: `#2b2b2b`
- Foreground: `#ffffff`
- Cursor: `#7f7f7f`
- Cursor text: `#ffffff`
- Selection: `#5a647e`
- Selection text: `#f2f2f2`
- Contrast: 14.16
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Rippedcasts theme was created by [mdw123](https://github.com/mdw123/rippedcasts)
- Made from: [iTerm2-Color-Schemes, ghostty/Rippedcasts](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Rippedcasts)

The dark terminal theme Rippedcasts: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
