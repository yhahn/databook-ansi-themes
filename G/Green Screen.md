# Theme: Green Screen

- Dark: yes
- Background: `#031009`
- Foreground: `#dff7e8`
- Cursor: `#8af0b4`
- Cursor text: `#031009`
- Selection: `#12351f`
- Selection text: `#effff4`
- Contrast: 17.20
- Same brights: 0
- Licence: unstated

The dark terminal theme Green Screen: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
