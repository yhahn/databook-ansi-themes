# Theme: GitHub Dark Colorblind

- Dark: yes
- Background: `#0d1117`
- Foreground: `#c9d1d9`
- Cursor: `#58a6ff`
- Cursor text: `#98e6ff`
- Selection: `#c9d1d9`
- Selection text: `#0d1117`
- Contrast: 12.26
- Same brights: 0

- Default: yes
- Featured: no

These themes were converted from the [official GitHub theme](https://github.com/primer/github-vscode-theme) using the [ditto](https://github.com/campvanilla/ditto) tool.
- Made from: [iTerm2-Color-Schemes, ghostty/GitHub Dark Colorblind](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/GitHub%20Dark%20Colorblind)

The dark terminal theme GitHub Dark Colorblind: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
