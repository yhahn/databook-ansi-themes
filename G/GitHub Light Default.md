# Theme: GitHub Light Default

- Dark: no
- Background: `#ffffff`
- Foreground: `#1f2328`
- Cursor: `#0969da`
- Cursor text: `#3c9cff`
- Selection: `#1f2328`
- Selection text: `#ffffff`
- Contrast: 15.80
- Same brights: 0

- Default: yes
- Featured: yes

These themes were converted from the [official GitHub theme](https://github.com/primer/github-vscode-theme) using the [ditto](https://github.com/campvanilla/ditto) tool.
- Made from: [iTerm2-Color-Schemes, ghostty/GitHub Light Default](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/GitHub%20Light%20Default)

The light terminal theme GitHub Light Default: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
