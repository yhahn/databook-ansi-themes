# Theme: GitLab Dark

- Dark: yes
- Background: `#28262b`
- Foreground: `#ffffff`
- Cursor: `#ffffff`
- Cursor text: `#bfbfbf`
- Selection: `#ad95e9`
- Selection text: `#28262b`
- Contrast: 14.97
- Same brights: 1
- Licence: unstated
- Licence from:
- Default: no
- Credit: The GitLab Dark, GitLab Dark Grey, and GitLab Light themes were added by [Antonio Camargo](https://github.com/apcamargo). These themes were converted from the theme created by [albertorestifo](https://github.com/albertorestifo/gitlab-webide-theme) using the [ditto](https://github.com/campvanilla/ditto) tool.
- Made from: [iTerm2-Color-Schemes, ghostty/GitLab Dark](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/GitLab%20Dark)

The dark terminal theme GitLab Dark: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
