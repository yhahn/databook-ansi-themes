- Dark: yes
- Background: `#0a0c10`
- Foreground: `#f0f3f6`
- Cursor: `#71b7ff`
- Cursor text: `#b1f7ff`

The dark terminal theme GitHub Dark High Contrast: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
