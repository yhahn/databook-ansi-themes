# Theme: GitHub Light Colorblind

- Dark: no
- Background: `#ffffff`
- Foreground: `#24292f`
- Cursor: `#0969da`
- Cursor text: `#3c9cff`
- Selection: `#24292f`
- Selection text: `#ffffff`
- Contrast: 14.65
- Same brights: 0

- Default: yes
- Featured: no

The light terminal theme GitHub Light Colorblind: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
