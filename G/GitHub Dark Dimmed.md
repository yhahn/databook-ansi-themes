# Theme: GitHub Dark Dimmed

- Dark: yes
- Background: `#22272e`
- Foreground: `#adbac7`
- Cursor: `#539bf5`
- Cursor text: `#93dbff`
- Selection: `#adbac7`
- Selection text: `#22272e`
- Contrast: 7.60
- Same brights: 0

The dark terminal theme GitHub Dark Dimmed: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
