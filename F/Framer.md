# Theme: Framer

- Dark: yes
- Background: `#111111`
- Foreground: `#777777`
- Cursor: `#fcdc08`
- Cursor text: `#161616`
- Selection: `#666666`
- Selection text: `#ffffff`
- Contrast: 4.22
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The Framer theme was created by [markogresak](https://github.com/markogresak) based on [Framer Syntax Theme](https://www.producthunt.com/posts/framer-syntax-theme) provided by [Framer](https://framer.com).
- Made from: [iTerm2-Color-Schemes, ghostty/Framer](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/Framer)

The dark terminal theme Framer: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
