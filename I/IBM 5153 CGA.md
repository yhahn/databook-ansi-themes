# Theme: IBM 5153 CGA

- Dark: yes
- Background: `#141414`
- Foreground: `#cecece`
- Cursor: `#cecece`
- Cursor text: `#141414`
- Selection: `#cecece`
- Selection text: `#141414`
- Contrast: 11.71
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The IBM 5153 CGA themes were created by [Jesse Miller](https://jmiller.com/). Based on The IBM 5153's True CGA Palette and Color Output [int10h.org/blog](https://int10h.org/blog/2022/06/ibm-5153-color-true-cga-palette/).
- Made from: [iTerm2-Color-Schemes, ghostty/IBM 5153 CGA](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/IBM%205153%20CGA)

The dark terminal theme IBM 5153 CGA: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
