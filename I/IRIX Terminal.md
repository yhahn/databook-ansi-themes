# Theme: IRIX Terminal

- Dark: yes
- Background: `#000043`
- Foreground: `#f2f2f2`
- Cursor: `#c7c7c7`
- Cursor text: `#8c8c8c`
- Selection: `#c2deff`
- Selection text: `#000000`
- Contrast: 17.35
- Same brights: 0
- Licence: unstated
- Licence from:
- Default: no
- Credit: The IRIX Console and IRIX Terminal themes were created, based on screenshots from [CompuHacker/](https://www.reddit.com/user/CompuHacker/) on [Reddit](https://www.reddit.com/r/IRIX/comments/1iohgt4/any_irix_user_able_to_help) by [Skeeve](https://github.com/Skeeve). [IRIX](https://en.wikipedia.org/wiki/IRIX) was the operating system of Silicon Graphics Computers.
- Made from: [iTerm2-Color-Schemes, ghostty/IRIX Terminal](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/c379d7a31af861838a017468b03120c8970eaa00/ghostty/IRIX%20Terminal)

The dark terminal theme IRIX Terminal: its background, text, cursor and selection, and the sixteen colours a terminal names 0 to 15. Contrast is its text's against its background (WCAG; 4.5 reads well, 7 very well).
